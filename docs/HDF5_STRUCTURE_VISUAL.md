# HDF5 文件结构可视化说明

## 📁 单个 HDF5 文件，多层结构

```
assays.h5 (7.2 MB)
│
┌─────────────────────────────────────────────────┐
│              HDF5 文件根 (/)                    │
├─────────────────────────────────────────────────┤
│                                                 │
│  🎯 数据层 1: Matrix Data (直接在根级)           │
│  ┌───────────────────────────────────────────┐  │
│  │  📄 beta                                 │  │
│  │     Type: FLOAT                            │  │
│  │     Dim:  [80028, 2]                       │  │
│  │     Data:  甲基化值矩阵                     │  │
│  │            80,028 CpG × 2 样本               │  │
│  │                                          │  │
│  │  📄 cov                                  │  │
│  │     Type: INTEGER                          │  │  │
│  │     Dim:  [80028, 2]                       │  │
│  │     Data:  覆盖度矩阵                       │  │
│  │            80,028 CpG × 2 样本               │  │
│  └───────────────────────────────────────────┘  │
│                                                 │
│  📍 数据层 2: Row Data (rowData 组)              │
│  ┌───────────────────────────────────────────┐  │
│  │ Group: /rowData/                            │  │
│  │  ├─ 📄 chr      [STRING: 80028]           │  │

│  │  └─ 📄 strand   [STRING: 80028]           │  │
│  │                                              │  │

│  └───────────────────────────────────────────┘  │
│                                                 │

│  └───────────────────────────────────────────┘  │

│  │  └─ 📄 is_h5    [ENUM: 1]                 │  │
│  │                                              │  │
│  │  💡 这就是元数据！                           │  │
│  └───────────────────────────────────────────┘  │
│                                                 │
└─────────────────────────────────────────────────┘
```

## 🔍 关键特性

### 1. 单文件架构
- **一个 HDF5 文件**包含所有数据
- 不需要额外的辅助文件
- 便于传输和存储

### 2. 层级组织
```
根 (/)
├── beta (数据集)
├── cov (数据集)
├── rowData (组)
├── colData (组)
└── metadata (组)
```

### 3. 数据维度一致性
所有矩阵都是 **[80,028 x 2]**：
- beta: 80,028 CpG 位点 × 2 样本
- cov: 80,028 CpG 位点 × 2 样本
- rowData: 80,028 行 (每个 CpG 位点一行)
- colData: 2 行 (每个样本一行)

### 4. 坐标信息完整性

rowData 组包含每个 CpG 位点的完整坐标：

```
位点 1: chr="chr1", start=133164, end=133166, strand="+"
位点 2: chr="chr1", start=133179, end=133181, strand="+"
位点 3: chr="chr1", start=799120, end=799122, strand="+"
...
```

**对应基因组坐标**:
- 1-based: `chr1:133165-133166:+`
- 0-based: `chr1:133164-133166:+`

## 💡 与 R methrix 的关系

### R methrix 的目录结构

```
output_dir/
├── assays.h5          # HDF5 文件 (我们生成的)
├── se.rds             # SummarizedExperiment 对象
└── CpG_coverage.xlsx # QC 报告
```

### 我们的生成方式

**Rust methrix-cli**:
```
Rust 处理
    ↓
assays.h5  (单个文件，包含所有层)
    ↓
se.rds     (R SummarizedExperiment 对象)
```

**R methrix**:
```
R 处理
    ↓
assays.h5  + se.rds  (分离的文件)
```

## 🎯 总结

### 您的理解完全正确！✅

1. **单个 HDF5 文件** ✅
   - 文件名: `assays.h5`
   - 大小: ~7.2 MB
   - 包含所有数据层

2. **多个层级结构** ✅
   - **Matrix 层**: beta, cov
   - **Row Data 层**: chr, start, end, strand (rowData 组)
   - **Column Data 层**: sample_id (colData 组)
   - **Metadata 层**: genome, is_h5 (metadata 组)

3. **有 CpG 坐标信息** ✅
   - 存储在 `rowData` 组中
   - 包含: 染色体、起始位置、结束位置、链
   - **没有单独的 cpg_id 字段**
   - 可用 `chr:start+1` 作为唯一标识符

这个设计是 R/Bioconductor 的标准格式，与 R methrix 包完全兼容！
